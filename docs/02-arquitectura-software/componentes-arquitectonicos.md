# Componentes arquitectónicos de Qatu

La API contiene seis módulos: Usuarios, Proveedores, Catálogo, Reservas, Reputación/confianza y Búsqueda inteligente. Pagos pertenece a Reservas; publicación outbox, adaptadores, seguridad y observabilidad son soporte técnico.

La vista completa con relaciones, responsabilidades y propiedad de datos está en [C4 nivel 3](../04-modelo-c4/Nivel3-Diagrama-de-Componentes.md). Para aplicaciones y almacenes ver [C4 nivel 2](../04-modelo-c4/Nivel2-DiagramadeContenedores.md). Para clases/puertos ver [C4 nivel 4](../04-modelo-c4/Nivel4-DiagramadeCodigo.md).
